Video to GIF converter

안전하고 빠른 동영상 GIF 변환 서비스

이 사이트는요

Video to GIF는 동영상을 GIF로 바꿔 주는 무료 웹 도구예요. 파일을 서버에 올리지 않고, 지금 쓰고 계신 브라우저 안에서 변환합니다. 회원가입이나 설치도 필요 없어요.

버그 리포트나 블로그 글에 GIF를 자주 쓰는 개발자 한 명이 만들고 운영하고 있습니다. 쓰던 변환 사이트들이 파일을 외국 서버에 올려야 했고 색감도 아쉬워서 직접 만들게 됐어요. 자세한 이야기는 이 글에 적어 두었습니다.

신경 써서 만든 부분

🔒

파일이 내 컴퓨터를 떠나지 않아요

변환은 브라우저 안에서 끝납니다. 정말 업로드가 안 되는지 개발자 도구로 직접 확인하는 방법도 따로 정리해 뒀어요.

💎

색감

FFmpeg, 네이버 블로그 앱과 같은 영상으로 직접 비교해 보고 gifski 인코더를 골랐습니다. 비교 과정은 gifski 글에 있어요.

🎛️

꼭 필요한 설정만

프레임 간격, 가로 크기, 품질, FPS 네 가지만 넣었어요. 기본값으로도 쓸 만하고, 각 값이 뭘 바꾸는지는 설정 정리 글에서 볼 수 있습니다.

🧩

조금씩 고치는 중

처음엔 변환만 됐는데, 지금은 GIF 자르기와 글자 넣기도 됩니다. 필요한 기능이 있으면 문의하기로 알려 주세요.

지금 할 수 있는 것

  • ✅ MP4, MOV, WebM 등 브라우저에서 재생되는 동영상을 GIF로 변환
  • ✅ 프레임 간격(0.1초부터), FPS(1~60) 조절
  • ✅ 출력 가로 크기 조절 (최대 900px, 이유)
  • ✅ 품질 설정 (1~100, 클수록 고화질)
  • ✅ GIF에 글자 넣기, 끌어서 위치 옮기기
  • ✅ 만든 GIF에서 원하는 구간만 남기기 (GIF 자르기)
  • ✅ 한국어 / English 페이지

어떻게 동작하나요

  • HTML5 Video + Canvas - 고른 파일을 브라우저 안에서만 통하는 임시 주소로 열고, 프레임 간격마다 그 시점의 장면을 캔버스에 원하는 크기로 그려서 떠 둡니다.
  • gifski-wasm - Rust로 만든 GIF 인코더 gifski를 WebAssembly로 컴파일한 버전이에요. 장면마다 팔레트를 따로 잡아서 256색 한계 안에서도 색을 잘 살립니다.
  • WebAssembly - 브라우저에서 기계어에 가까운 속도로 코드를 돌리는 기술이에요. 덕분에 서버 없이도 인코딩을 할 수 있습니다.
  • Jekyll + GitHub Pages - 사이트는 정적 페이지로 만들어 GitHub Pages에 올려 두었어요. 변환을 서버에서 하지 않으니 따로 서버가 필요 없습니다.
