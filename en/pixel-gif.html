How to use

  1. Add a video

    Drop a video on the box above or click to choose one. It's processed inside your browser and never uploaded.

  2. Pick the size and the moment

    Choose 16×16, 32×32 or 64×64 to match your display. Drag on the original to move the square that goes into the GIF, then set the start and length. The preview on the right loops the real result as you change things.

  3. Make and save

    Press Make pixel GIF and save it. You get the original-size file and a large copy with each pixel scaled up.

Good to know

  • 16×16 is only 256 pixels, so faces and text are hard to read. Big, simple shapes with a clear color difference from the background work best. Move the square while watching the preview.
  • Pixel animation is usually made at 8 to 12 frames per second. For a device, start with 10 fps and 2 to 4 seconds.
  • Each pixel's color is the average of all the source pixels that fall into it, so you get less shimmering and fewer broken dots than with a plain resize.
  • Pixel displays like Divoom can load a GIF from their app. Making it at the same size as the screen lets you see exactly which color each pixel will be. Apps may limit the number of frames or the file size, so if it won't load, shorten it or drop to 5 fps.
