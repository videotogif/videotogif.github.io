🐛 Bug Reports

If something went wrong while using the service, please include the following:

  • Browser and version (e.g., Chrome 120.0, Safari 17.1)
  • Operating system (e.g., Windows 11, macOS 14.0, Android 13)
  • When the error happened (while uploading the video, generating the GIF, downloading, etc.)
  • Error message (a screenshot is even better)
  • Video file details (format, file size, length)

The more detail you give me, the faster I can fix the problem. You don't need to send video files that contain personal information; I can test with a sample file under similar conditions.

Common Questions

Conversion is too slow. What should I do?

Conversion speed depends on the video's length, resolution and your device's performance. For faster conversion, shorten the video to 10 seconds or less and set the output size to 500px or less. Increasing the frame interval to 0.3 seconds or more also helps, since there are fewer frames to process.

It doesn't work well on my phone.

Mobile devices have less memory and processing power than computers. On mobile, I recommend short clips of 5 seconds or less and an output size of 400px or less. For long videos or high-resolution conversions, please use a computer.

Can I use it commercially?

Yes, the service is free and you can use it for commercial purposes too. However, the copyright of a GIF you create follows the copyright of the original video, so you need the legal right to use the original content. The site's source code is public on GitHub under the MIT license. The blog posts, images, and the "Video to GIF" name and logo, however, can't be reused without permission.
