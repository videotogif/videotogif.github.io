제가 GIF를 제일 많이 만드는 순간은 버그를 설명할 때예요. "버튼을 두 번 누르면 메뉴가 깜빡여요"를 글로 쓰는 것보다, 3초짜리 GIF 하나 붙이는 게 훨씬 빨리 전해지거든요. 그래서 이 사이트를 만들 때도 화면 녹화 영상을 넣는 경우를 제일 먼저 생각했습니다.

이 글은 따로 프로그램을 깔지 않고, 맥과 윈도우에 원래 들어 있는 기능만으로 화면을 찍어서 GIF로 바꾸는 과정이에요.

## 1. 화면 녹화하기

### 맥: ⌘ + Shift + 5

1. **⌘ + Shift + 5**를 누르면 화면 아래에 막대가 하나 뜹니다.
2. 오른쪽 두 버튼이 녹화예요. **전체 화면 기록**과 **선택 부분 기록** 중에서, GIF용이라면 거의 항상 **선택 부분 기록**을 고릅니다.
3. 찍을 영역을 드래그로 정하고 **기록**을 누르면 시작돼요.
4. 끝낼 때는 메뉴 막대 오른쪽 위의 정지 버튼(■)을 누르거나 **⌘ + Control + Esc**를 누르면 됩니다.

저장된 파일은 기본으로 데스크탑에 `.mov`로 생깁니다. 같은 막대의 **옵션**에서 저장 위치를 바꾸거나, 클릭할 때 동그라미가 보이게 하는 **마우스 클릭 보기**를 켤 수 있어요. 버그 재현용이라면 클릭 표시를 켜 두는 걸 추천합니다. 어디를 눌렀는지가 같이 보이니까요.

### 윈도우 11: Win + Shift + R

1. **Win + Shift + R**을 누르면 캡처 도구의 녹화 모드가 열려요. (Win + Shift + **S**는 스크린샷이라 헷갈리기 쉬워요.)
2. 찍을 영역을 드래그하고 **시작**을 누릅니다.
3. 끝나면 정지 버튼을 누르고, 캡처 도구 창에서 저장하면 돼요.

파일은 `.mp4`로, 보통 **동영상 > Screen Recordings** 폴더에 저장됩니다. 단축키가 안 먹으면 Microsoft Store에서 캡처 도구를 업데이트해 보세요. 키를 바꿔 주는 프로그램이 같은 단축키를 쓰고 있어서 안 되는 경우도 있습니다.

게임이나 특정 앱 창 하나만 찍을 때는 **Win + Alt + R**(Xbox Game Bar)도 됩니다. 다만 이건 앱 창 단위로 찍혀서, 바탕화면이나 파일 탐색기는 잘 안 잡혀요. GIF용으로는 영역을 직접 고르는 캡처 도구 쪽이 편합니다.

## 2. 영상을 GIF로 바꾸기

찍은 `.mov`나 `.mp4`를 [Video to GIF 변환기](/)에 끌어다 놓으면 됩니다. 변환은 지금 쓰고 계신 브라우저 안에서 일어나서 파일이 어디에도 올라가지 않아요. 회사 화면이나 아직 공개 전인 화면을 찍었을 때 이게 생각보다 중요하더라고요.

영상을 넣으면 길이와 해상도를 보고 설정이 자동으로 정해지고, 화질 눈금(저사양~고사양)으로 한 번에 조절할 수 있어요. 화면 녹화라면 대부분 그대로 만들어도 괜찮고, 아래 요령만 알아 두면 결과가 훨씬 좋아집니다.

브라우저가 못 여는 형식이면 안내 창이 떠요. 맥 기본 녹화(.mov)와 윈도우 캡처 도구(.mp4)는 크롬, 엣지, 사파리에서 보통 바로 열립니다.

## 3. 글자가 뭉개지지 않게 찍는 요령

화면 녹화 GIF에서 제일 아쉬운 건 글자가 흐려지는 거예요. 원인은 대부분 **찍은 크기보다 GIF가 작아져서**입니다.

맥의 레티나 화면은 실제 픽셀이 보이는 크기의 2배예요. 화면에서 가로 600 정도로 보이는 영역을 찍으면, 영상은 가로 1200픽셀로 저장됩니다. 그런데 이 변환기는 GIF의 긴 쪽을 최대 900픽셀까지만 만들어요(이유는 [이 글](/blog/why-900px/)에 적어 두었습니다). 그러면 1200이 900으로 줄면서 글자가 조금 뭉개져요.

그래서 저는 이렇게 찍습니다.

- **영역을 작게 잡기.** 버그가 일어나는 부분만 찍으면 GIF로 줄일 일이 줄어듭니다. 전체 화면은 거의 안 써요.
- **브라우저 확대 배율 올리기.** 웹 화면이라면 ⌘(Ctrl) + `+`로 125~150%쯤 키우고 찍으면, 같은 크기로 줄여도 글자가 읽혀요.
- **'직접 설정'에서 크기를 원본에 맞추기.** 찍은 영상이 900픽셀보다 작다면 크기를 원본과 같게 두는 게 제일 선명합니다. 키워 봤자 흐려지기만 해요.

## 4. 용량을 작게 유지하는 요령

화면 녹화는 일반 영상보다 GIF로 바꾸기 좋은 재료예요. 색이 적고 화면 대부분이 가만히 있어서, 같은 길이라도 용량이 작게 나오는 편입니다. 그래도 아래 세 가지는 챙기는 게 좋아요.

- **5~10초 안으로.** 길이는 용량에 그대로 곱해집니다. 앞뒤로 마우스를 찾는 시간이 들어갔다면 [GIF 자르기](/gif-trim/)에서 잘라 내세요.
- **초당 장수는 10장이면 충분.** 클릭하고 메뉴가 열리는 정도의 움직임은 초당 10장으로도 자연스러워요. 스크롤처럼 화면이 크게 움직이는 장면만 더 올리면 됩니다.
- **찍기 전에 화면 정리.** 알림, 시계 초 단위 표시, 움직이는 광고처럼 계속 바뀌는 부분이 있으면 그만큼 용량이 커져요.

어디에 올릴지에 따라 넘으면 안 되는 크기가 있어요. 깃허브 이슈에 붙인다면 [깃허브 GIF 글](/blog/github-gif/)을, 그 밖의 용량 줄이는 순서는 [GIF 용량 줄이는 법](/blog/reduce-gif-size/)을 참고해 주세요.

## 정리

1. 맥은 **⌘ + Shift + 5**, 윈도우 11은 **Win + Shift + R**로 필요한 영역만 찍기
2. 찍은 영상을 [변환기](/)에 넣기 (파일은 브라우저 밖으로 안 나가요)
3. 글자가 흐리면 영역을 줄이거나 화면을 확대해서 다시 찍기
4. 길면 [GIF 자르기](/gif-trim/)로 앞뒤 정리
